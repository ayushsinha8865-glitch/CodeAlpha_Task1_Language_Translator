# 🌐 AI Language Translator — CodeAlpha Task 1

A modern multilingual language translator developed as part of **CodeAlpha Task 1** using Python Flask, JavaScript, HTML, and CSS.

The application supports translation between multiple **Indian and international languages**, along with voice input and text-to-speech functionality.

## ✨ Features

- 🌍 Multilingual text translation
- 🇮🇳 Indian language support
- 🌎 International language support
- 🎤 Voice input using Web Speech API
- 🔊 Text-to-speech output
- 🔄 Source/target language swapping
- 📋 Copy translated text
- 🧹 Clear input and output
- 🔢 Character counter
- ✨ Professional splash screen with loading animation
- 📱 Responsive and compact user interface
